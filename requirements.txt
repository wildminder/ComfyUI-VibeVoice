# Runtime dependencies for ComfyUI-Manager / git-clone installs.
# Only packages NOT bundled with ComfyUI itself are listed here — torch,
# numpy, safetensors and tqdm ship with every ComfyUI (see ComfyUI's own
# requirements.txt). The full declared dependency surface lives in
# pyproject.toml (used by the Comfy registry); every entry here must be a
# subset of it (guarded by tests/test_pyproject.py).
#
# torchaudio is bundled with ComfyUI but is still declared explicitly: it
# is this node's primary audio resampler/encoder backend and tests lock
# it as a hard dependency.
#
# accelerate: required by the transformers 4-bit (BitsAndBytesConfig) path;
#   not guaranteed by ComfyUI's own requirements at our floor (v0.28.0).
accelerate
torchaudio
huggingface_hub
soundfile
# transformers is bounded to the 5.3.x line — the version this node is
# developed, tested and shipped against, and the only green realtime row in
# docs/plans/2026-09-26-two-version-matrix.md. Do NOT re-add a "<5" cap here:
# ComfyUI's own requirements declare transformers>=4.50.3, so a sub-5.0 pin
# makes a Manager install downgrade a package this node does not own, and it
# would also break the shipped ASR node, which needs >= 5.3.0. See the comment
# in pyproject.toml for the full rationale; keep the two in sync.
transformers>=5.3.0,<5.4
diffusers
bitsandbytes
